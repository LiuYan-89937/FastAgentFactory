# Combo 官网前端开发规格

## 1. 产品边界

官网用于展示 Combo 动态 Agent Runtime，并提供：

- 产品介绍与真实界面组件演示；
- macOS、Windows 安装包下载与累计下载次数；
- 桌面应用更新日志；
- 使用指南和 GitHub 仓库入口；
- 桌面端 GitHub Browser OAuth 的服务端支持；
- 不在公开导航中出现的版本发布与错误上报管理控制台。

官网不提供运行时能力社区、能力搜索、上传、下载、静态校验或人工审核。桌面端也不从官网导入运行时能力。

## 2. 目标架构文案

产品叙事必须与动态运行时一致：

```text
统一对话
  → 自动 / 快速 / 计划路由
  → 从 Skill、Tool、MCP、Dependency 四池解析能力
  → 主 Agent 自行执行或创建临时 Agent
  → 在本地工作区产生文件、产物与可恢复状态
```

禁止重新引入已经移除的目录包、多入口工作流、实例分发或社区能力市场。

## 3. 页面与路由

| 路由 | 内容 | 权限 |
|---|---|---|
| `/` | 产品、动态运行时演示、架构边界、下载 | 公开 |
| `/guide` | 安装、模型、统一对话、能力池、工作区与审批 | 公开 |
| `/changelog` | 应用 Release 与更新日志 | 公开 |
| `/ops` | 应用 Release 与错误上报管理 | 管理地址令牌 |

未知旧路由必须进入统一 404，不得跳回已删除页面。

## 4. 首页结构

### Hero

- 强调“统一对话 + 动态能力 + 本地工作区”。
- 主操作为下载应用，次操作为 GitHub。
- 不提供“探索 Hub”或“发布 Agent”入口。

### 产品实景演示

使用与桌面应用一致的 Vue 组件和假数据进行只读循环演示，不使用截图或录屏。演示内容只覆盖：

- 统一对话与 ReAct/计划路由；
- 临时 Agent 协作；
- 工作区文件与产物；
- Skill、Tool、MCP 能力选择；
- 工具审批与任务进度。

循环动画不得改变页面滚动位置、抢夺焦点或触发真实 API。

### 执行链路

固定为模型 → 路由 → 能力解析 → 执行 → 协作，不再展示制造或分发步骤。

### 架构边界

- Desktop app：本地运行时、会话、工作区与能力池。
- Release service：认证、更新日志、安装包、Updater 元数据与下载计数。

### 下载

下载卡片必须来自 `GET /api/v1/config/public`。没有真实 URL 时禁用按钮，不允许伪造可下载状态。

## 5. 管理员控制台

管理员控制台管理应用 Release 与错误上报：

- 创建版本和更新日志；
- 上传安装包、更新包和签名；
- 查看资产状态与 GitHub 同步进度；
- 发布或撤回应用版本。
- 查看脱敏错误日志并更新处理状态。

公开页面不展示管理员导航。前端隐藏不是授权边界，后端必须再次校验管理员 Bearer 令牌。

## 6. 认证与安全

- 管理令牌通过 URL fragment 导入，不进入 HTTP 请求日志，并立即从地址栏移除。
- 管理令牌只保存在当前标签页的 sessionStorage，不写入 localStorage。
- 桌面端 OAuth state 必须校验且短时有效。
- 不在浏览器存储中保存 Session Cookie、GitHub Token 或 OSS 凭据。
- 公开错误显示稳定错误码和 request ID，不显示栈、SQL、文件路径或密钥。
- 外链使用 `noopener noreferrer`。

## 7. 国际化与可访问性

- 中文和英文目录必须结构一致。
- 默认语言遵循产品设置；切换结果可持久化。
- 所有按钮、表单、状态、失败原因和空状态均有双语文案。
- 键盘可访问，焦点可见，动画遵循 `prefers-reduced-motion`。
- 颜色对比、标题层级、表单 label 和动态状态提示满足基本 WCAG 要求。

## 8. 状态与缓存

- 主题、语言等无身份偏好可以保存在 localStorage。
- 管理地址必须向服务端验证后才加载控制台内容。
- 前端持久化状态使用独立 Schema 版本；升级时清理旧 Package 路由、Hub 选择和通知 target。
- 更新日志和公开配置允许短时缓存，管理员数据不得与公开缓存混用。

## 9. 验收

- TypeScript 与 Vue 类型检查通过。
- `/hub`、`/publish` 和 Package detail 不在路由、sitemap、robots、导航或构建 chunk 中。
- 中英文源码不包含已经移除的目录包、多入口工作流或社区分发文案。
- 下载、管理员 Release、错误上报和 Updater 使用真实后端协议；静态构建成功不等于运行链路通过。
- 桌面实景演示不会自动滚动页面、抢焦点或调用生产写接口。
- 最终部署产物和源码执行同一旧语义扫描。
